# Roast Your Own Agent

Entry for the [make.fun Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c?ref=41fw6r6c) competition (`program/v1`).

Join make.fun via [https://make.fun/r/41fw6r6c](https://make.fun/r/41fw6r6c).

## Usage

Runs on Node 22+ and writes a deterministic single-line UTF-8 roast (1–200 characters) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set locally):

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
